# Инструкция по запуску проекта

Полное руководство по быстрому запуску проекта T1 Hack с использованием Docker Compose.

## 📋 Требования

Перед началом работы убедитесь, что у вас установлены:

- **Docker** версии 20.10 или выше
- **Docker Compose** версии 2.0 или выше

### Проверка установки

```bash
docker --version
docker compose version
```

Если Docker не установлен, скачайте его с официального сайта:

- Windows/Mac: [Docker Desktop](https://www.docker.com/products/docker-desktop)
- Linux: следуйте инструкциям для вашего дистрибутива

## 🚀 Быстрый запуск

### 1. Клонирование проекта

Если проект еще не склонирован, выполните:

```bash
git clone <repository-url>
cd t1-hack
```

### 2. Запуск всех сервисов

Из корневой директории проекта выполните:

```bash
docker compose up -d
```

Эта команда:

- Соберет образы для всех сервисов
- Запустит контейнеры в фоновом режиме
- Настроит сеть между сервисами
- Поднимет базу данных

### 3. Ожидание запуска

При первом запуске может потребоваться время для:

- Сборки Docker образов
- Загрузки зависимостей
- Применения миграций базы данных

Проверьте статус контейнеров:

```bash
docker compose ps
```

Все сервисы должны иметь статус `Up` (или `Up (healthy)` для базы данных).

## 🌐 Доступ к приложению

После успешного запуска приложение будет доступно по следующим адресам:

- **Frontend**: http://localhost:5173
- **Backend API**: http://localhost:8000
- **API документация (Swagger)**: http://localhost:8000/docs
- **ML Service**: http://localhost:8080
- **PostgreSQL**: localhost:5433

## 📊 Архитектура проекта

Проект состоит из следующих сервисов:

### Frontend (порт 5173)

React + TypeScript + Vite приложение

### Backend (порт 8000)

FastAPI приложение с:

- JWT аутентификацией
- REST API
- Интеграцией с ML сервисом
- Работой с PostgreSQL

### ML Service (порт 8080)

Микросервис для обработки интервью с использованием LLM

### Database (порт 5433)

PostgreSQL 15 база данных

## 📝 Переменные окружения

Основные переменные окружения настраиваются в `compose.yaml`:

- `JWT_SECRET` - секретный ключ для JWT токенов
- `DB_NAME`, `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD` - настройки БД
- `ALLOWED_ORIGINS` - разрешенные домены для CORS
- `ASSEMBLYAI_API_KEY` - ключ API для транскрипции аудио
- `SCIBOX_API_KEY` - ключ API для LLM
- `ML_API_URL` - URL ML сервиса

## ⚠️ Важные заметки

1. **База данных**: При использовании `docker compose down -v` все данные в базе будут удалены
2. **Порты**: Убедитесь, что порты 5173, 8000, 8080 и 5433 свободны
3. **API ключи**: Для работы некоторых функций требуются действительные API ключи
4. **Миграции**: Миграции базы данных применяются автоматически при запуске backend

## 🤝 Поддержка

При возникновении проблем:

1. Проверьте логи: `docker compose logs`
2. Убедитесь, что все порты свободны
3. Попробуйте пересобрать образы: `docker compose up -d --build`
